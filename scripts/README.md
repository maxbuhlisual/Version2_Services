# HTTP-проверка доступа к расходам

Из корня репозитория:

```sh
python3 scripts/check_expense_security.py
```

Нужны .NET 10 SDK, Python 3 и OpenSSL в PATH. Скрипт сам собирает решение,
запускает API на свободном локальном HTTPS-порту и проверяет независимые
сессии А, Б и гостя, коды 200/401/403, CSRF-отказы 400 и сохранность расходов
и Spent после каждого отказа. Также проверяются собственные категории и месячные
итоги А и Б, запрет чужих отчётов, подмены владельца и связанной категории
в POST категорий и бюджетов. После отказов сравниваются все строки категорий,
бюджетов и расходов. При расхождении или тайм-ауте команда завершается
с ненулевым кодом. Не используйте Python с флагом `-O`.

SQLite, ключ и сертификат создаются в отдельном временном каталоге и удаляются
после проверки. Сертификат доверен только HTTP-клиентам этого скрипта. Cookie
и CSRF-токены хранятся в памяти. Рабочая база не используется. API останавливается
в блоке `finally`. Временный пароль сертификата и данные пользователей вымышленные.
